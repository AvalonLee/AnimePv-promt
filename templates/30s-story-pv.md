# 30s Character Story PV

Template ID: template.character.story.30s.v1

## Purpose

主角、高人气角色、世界观角色、周年预告。

## Structure

```
0-10s    Identity     世界 / 角色身份 / 情绪建立
10-22s   Conflict     能力 / 战斗 / 内心变化
22-30s   Resolution    Hero Moment / Character Title
```

## Rules

允许环境叙事，但角色始终第一优先。
30s 允许 Action Level 3，五星角色允许 Effect Level 3。
