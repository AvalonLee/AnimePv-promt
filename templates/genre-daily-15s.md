## 完整可替换模板

```
生成一支约15秒、16:9横版、原创都市日常感角色宣传PV。
整体采用纯二维日式赛璐璐动画 + Editorial MG动态平面设计 + 日系潮流杂志封面风格。全片保持纯二维，禁止3D建模、CG渲染、真人摄影感、写实皮肤、真实空间纵深。

【角色设定】
角色外观严格参考输入角色：<替换为角色外貌：发型/发色/瞳色/服装/配饰/纹身>。
气质：<根据角色调整，如：自信魅惑、清冷疏离、甜美元气、飒爽利落>。表情可包括：回眸、挑眉、轻抿唇、撩发、眨眼、垂眸、轻笑、歪头。
角色一致性强制约束：发色、瞳色、服装、配饰全程一致，禁止脸崩、禁止五官变化、禁止服装随机变化、禁止肢体畸形、禁止手指错误。
安全边界：性感风格限定气质魅惑自信，保守非露骨，禁止过度裸露、禁止低俗。

【主题设定】
主题为"<替换主题名，如：DAILY GLIMPSE / 日常一瞥>"。
故事发生在一个由<替换场景：如霓虹楼道/街头便利店/校园走廊/咖啡馆窗边>构成的日常空间，叠加平面图形元素：杂志排版框、贴纸、半调网点、扫描线、手写箭头、几何色块、文字标签、胶片边框。
主色：<角色主色> + 场景主色 + 纯黑 + 纯白，高对比但柔和，可加入霓虹色点缀。
原创角色，原创日常世界，不出现现有IP和Logo。

【音乐】
100-120 BPM日系City Pop / Lo-Fi Hip Hop / 轻柔Electro Pop，融合柔和钢琴、慵懒Bass、轻碎鼓点、环境音（脚步声/风声/衣物摩擦/杯碟声）、短促合成器点缀。
开场用环境音+轻柔钢琴引入，0.5s内出现角色。
中段鼓点进入，节奏舒缓但有律动，每一次轻拍对应一次微表情或机位变化。
10s后情绪微微上扬，加入更多合成器层次。
结尾音乐逐渐稀疏，最后以一个轻柔音效+环境音结束。

【画面风格】
人物使用干净黑色轮廓线、平涂色块、柔和硬边阴影、克制高光，非写实光影，肌肤通透但不写实。
背景由手绘场景+平面图形叠加构成：杂志排版框、贴纸、半调网点、扫描线、手写箭头、几何色块、文字标签、胶片边框、速度线（轻柔版）。
整体像日系潮流杂志内页、日常系动画名场面、角色写真PV、胶片感日常短片。

【动态与转场总要求】
全片保持中高密度视觉变化，平均1-2秒一次机位或构图变化，禁止长时间静止，禁止普通淡入淡出，禁止空白过渡。
转场使用：头发甩过镜头遮挡、手掌掠过镜头遮挡、身体侧身遮挡、贴纸弹出覆盖、图层滑移、光圈开合、图形划像、色彩渐变溶解、胶片帧跳转、扫描线擦镜、文字标签推入。
多层叠加运动：前景贴纸/文字飞入、中景人物细微动作、后景场景视差滚动、图形元素轻微脉冲。
可闪现原创文字标签：<如角色名/DAILY/GLIMPSE/MOMENT/FILE/NO.01/PROFILE>。

【分时间段镜头设计】
0-1.5s：超近距离高机位俯拍，角色微微仰头看向镜头，一只手主动伸向镜头形成前景放大，脸部位于画面中央偏下，眼神直视观众，嘴角轻轻上扬。瞬间插入：眼睛极近特写→发夹→耳饰→项链→发尾。伴随主题文字碎片高速弹出、贴纸飞入、半调网点扩散。机位：高机位俯拍贴脸。
1.5-3s：切换为低机位微仰拍，角色一条腿向镜头前方迈出形成前景透视，身体向后微仰，一只手叉腰，另一只手撩起发尾。镜头由腿部缓慢向上移至脸部。人物微微歪头俯视镜头，表情自信又俏皮。背景几何色块缓慢平移，扫描线轻微滚动。机位：低机位仰拍→上移。
3-4.5s：突然切到45°侧上方超近距离，人物侧身靠近镜头，肩膀与脸部占据画面大部分，一只手扶住颈部/发尾，另一只手向后自然垂落。角色轻轻眯眼，对镜头露出浅笑。头发快速甩过镜头形成自然遮挡转场。机位：侧上方贴脸。
4.5-6s：切换到低机位后侧45°视角，人物向前漫步后突然回头，一只手轻拉住外套/裙摆，另一只手向后伸向镜头。手臂在前景被放大，身体形成柔和动态曲线。头发/配饰随动作轻微摆动。背景出现高速滑动的杂志分镜框、文字标签。机位：后侧45°低角度。
6-7.5s：切换到正面超广角近距离，角色主动向镜头俯身靠近，脸部缓慢放大，一只手轻托脸颊，另一只手用食指轻点镜头。随后缓慢眨眼。人物周围爆出轻柔贴纸、星星、爱心（按角色风格调整）和半调网点。机位：正面俯冲撞镜→缓推。
7.5-9s：切换到大角度荷兰式倾斜构图，人物侧坐在抽象几何色块/窗台上，一条腿向画面前方自然伸出形成近大远小，另一条腿侧向收起。一只手撑在身后，一只手托住脸颊。角色侧头看向镜头，表情甜美/清冷（按风格）。画面随轻拍连续进行色彩渐变、贴纸切换、胶片帧跳转。机位：荷兰角中景。
9-10.5s：镜头突然切到人物手边/脚边，沿身体缓慢向上平移：手部美甲→手腕配饰→腰部裙摆/腰带→上身服装→颈部项链→面部，最终停在低机位侧仰拍。角色双臂自然展开，身体微微转动，头发向外甩开。背景色块脉冲、文字标签环绕。机位：平移上升→侧仰拍。
10.5-12s：切换到近距离轻鱼眼广角，角色脸部主动贴近镜头，眼睛成为视觉中心。一只手从画面上方轻压镜头，另一只手在脸旁比出俏皮/酷感手势。人物挑眉、轻笑。画面周围同时出现放射状轻柔Graphic图形、杂志网点、贴纸、扫描线。机位：鱼眼贴脸。
12-13.5s：切换到高机位斜后方俯拍，人物缓慢转身，裙摆/头发/配饰产生夸张二维动画摆动。转身途中连续闪现三个不同姿态：侧身回头→双手轻举伸展→单手叉腰向镜头前倾。三个姿态使用杂志分镜框连续呈现，每格不同透视方向。机位：高位斜拍→分格展示。
13.5-15s：最后切换为低机位正面大透视英雄镜头/主视觉定格。人物身体向前一步，一只手伸向镜头形成巨大前景，另一只手自然摆放，身体微微侧转。直视镜头，露出最有记忆点的表情。背景所有图形、贴纸、文字、色块瞬间向人物身后收拢，完成最终角色海报定格。最后0.3s：角色微微侧眼/眨眼→画面定格。巨大原创标题<角色名或主题名>伴随轻柔确认音效结束。机位：低机位正面大透视主视觉定格。

【表演要求】
角色动作保持强烈二次元动画感，细腻、自然、有气场，带日常系的松弛与自信。
动作包括：伸手、撩发、回眸、眨眼、垂眸、挑眉、抿唇、歪头、叉腰、侧身、漫步、转身、托腮、轻点镜头。
不要写实表演，不要真实镜头式人物调度，不要夸张肢体形变。

【避免项】
禁止3D感、真人摄影感、写实皮肤、电影级光影、景深、真实材质、写实特效、高斯运动模糊。
禁止角色脸崩、五官变化、发型变化、服装变化、配饰消失、肢体畸形、多手多脚、手指错误、穿模。
禁止普通淡入淡出、空镜头、长时间静止、重复机位、重复动作、连续正面平视、慢节奏无变化铺垫。
禁止未成年外观（如角色为成年）、过度暴露、低俗内容、现有IP/Logo/水印。

【核心目标】
重点突出角色日常魅力、细腻微表情、大透视多机位变化、中高密度转场、日系杂志感、纯二维平面设计感。整支片子像一支节奏舒适、机位丰富、角色魅力拉满的日常系角色写真PV。
```

## 5s / 10s 适配

- **5s**：取 `0-1.5s`（俯拍伸手建立）+ `4.5-6s`（后侧回头）+ `13.5-15s`（主视觉定格）三段，
  压缩为 `0-1.5s / 1.5-3.5s / 3.5-5s`
- **10s**：取 `0-1.5s` + `3-4.5s` + `6-7.5s` + `9-10.5s` + `13.5-15s` 五段，等比压缩
- 任何时长都必须保持：机位至少变化 3 次、禁止单镜头到底、最后 0.5s 定格 + 标题、禁止普通淡入淡出
