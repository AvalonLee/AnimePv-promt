# 双人 PV 15s 完整 Prompt 模板

Cast: duo（双人）
Template ID: `template.cast.duo.15s.v1`

> 生成前必须先读 [core/prompt-structure.md](../core/prompt-structure.md) 与
> [director/multi-character-composer.md](../director/multi-character-composer.md)。
>
> 默认 Base Style：`modern-cel`。如需厚涂 / 水彩国风 / 矢量潮流 / 韩漫 / 美漫，
> 将下方赛璐璐锚定与禁止项替换为 [core/style-anchor.md](../core/style-anchor.md) 中对应锚定。

---

## 使用前提（不满足则不要用本模板）

1. 两名角色至少在 **2 个维度**强对比（发色 / 剪影 / 服装色 / 身形 / 标志物）
2. 权重已确定：`lead 45 / second 25`
3. 构图锚位已固定：例如 lead 恒在左、second 恒在右，**全片不互换**
4. 同框段落只使用 `action_level 1` 组件（因同框会使有效等级 +1）

## 完整可替换模板

```
生成一支约15秒、16:9横版、原创双人角色宣传PV。
整体采用纯二维日式赛璐璐动画 + 战斗漫画分镜风格 + 高冲击力动漫海报动态视觉。全片保持纯二维，禁止3D建模、CG渲染、真人摄影感、写实皮肤、真实空间纵深。

【角色设定】
本片包含两名角色，二者外观必须全程清晰可区分，禁止特征互换、禁止五官融合、禁止生成第三个介于两者之间的角色。

角色A（主角，画面权重约45%，固定位于画面<A锚位，如：左侧>）：
<替换为角色A外貌：发型/发色/瞳色/服装/武器/配饰>。
气质：<角色A气质>。

角色B（次角，画面权重约25%，固定位于画面<B锚位，如：右侧>）：
<替换为角色B外貌：发型/发色/瞳色/服装/武器/配饰>。
气质：<角色B气质>。

角色一致性强制约束：两人的发色、瞳色、服装、武器全程各自保持一致；禁止A的发色/服装特征出现在B身上，禁止B的特征出现在A身上；禁止脸崩、禁止五官变化、禁止肢体畸形、禁止手指错误、禁止两人手部在前景交叠、禁止武器在同一帧交叉。

【主题设定】
主题为"<替换主题名，如：CROSSED BLADES / 交锋>"。
两人关系为<替换关系：宿敌/同伴/师徒/血亲/对立阵营>，关系张力为<低/中/高>。
关系的视觉表达方式：<替换，如：对峙+背对背 / 并肩前行 / 高低位差>。
故事发生在一个由<替换抽象空间元素>组成的抽象空间。
主色：<共享底色> + <角色A强调色> + <角色B强调色> + 纯黑 + 纯白，同框总色数不超过5种。
原创角色，原创世界，不出现现有IP和Logo。

【音乐】
<替换BPM与风格，如：140-160 BPM日系战斗摇滚>，融合<乐器与音效元素>。
开场0.5s直接切入，不做慢铺垫。
两人各自登场时对应两个不同的音乐动机，形成听觉区分。
首次同框时音乐合流，强化关系揭示。
结尾在最强一击后突然静音，以余韵结束。

【画面风格】
人物使用粗黑漫画线条、大面积纯色块、硬边阴影、白色高光，非写实光影。
两名角色的色彩体系必须明确分离，避免同框时视觉混淆。
背景由<替换背景图形元素>构成。

【动态与转场总要求】
全片平均0.3-0.8秒一次视觉变化，禁止长时间停顿，禁止空白过渡，禁止普通淡入淡出。
转场使用：闪白硬切、冲击拉伸、运动轨迹匹配、速度线推切、漫画分格跳切、图形碰撞、分割画面滑移。
两人交替出现时优先使用分格/分割转场，降低同框生成风险。
可闪现原创文字：<替换文字元素>。

【分时间段镜头设计】
0-2s：角色A单人登场。超近距离脸部特写，A锐利眼神直视镜头。瞬间插入：眼睛特写→武器细节→标志配饰。伴随闪屏、速度线爆发、主题文字碎片撞入。本段禁止B出现。机位：正面贴脸特写。
2-4s：角色B单人登场。超低机位仰拍，B一条腿向镜头前方迈出形成前景透视，身体后仰蓄力。镜头由腿部快速上甩至脸部。本段禁止A出现，机位必须与上一段不同。机位：仰拍→向上甩镜。
4-5.5s：角色A能力展示。侧面45°中景，A侧身冲刺，身后拖出3层离散残影，手绘放射速度线充满画面。单人镜头，可使用高动作等级。机位：侧面跟拍→急停。
5.5-7s：角色B能力展示。正面超广角近距离，B向镜头俯身出招，招式成为巨大前景，脸部在后方。单人镜头。机位：正面俯冲撞镜。
7-10s：关系揭示，首次同框。两人<替换同框构图，如：背对背站立，视线朝相反方向>，A在<A锚位>，B在<B锚位>，形成强烈的合成剪影。镜头缓慢推进。本段为全片卖点核心，动作保持静态定格，仅衣角与发丝微动。机位：中景双人缓推。
10-11.5s：交替快切制造互动感。连续闪现：A的锐利眼神→B的挑眉→A的武器→B的武器，每段约0.35s，使用漫画分格爆闪，每格只出现一人。机位：分格爆闪。
11.5-13s：同框对峙。两人分居画面左右，中央留出张力空白，视线在画面中央交汇。镜头沿视线轴缓慢横移。动作静态。机位：中景对峙横移。
13-15s：双人定格收尾。两人保持<替换最终构图>，A在<A锚位>，B在<B锚位>，背景所有图形元素瞬间向两人身后收拢。最后0.3s：画面定格，巨大原创标题<主题名>伴随重击音效结束。机位：超低机位正面大透视双人定格。

【表演要求】
两名角色动作保持强烈二次元动画感，各自性格通过动作与表情区分。
单人段落可使用夸张动作；同框段落必须以静态姿态与视线关系承载表达，禁止两人同时做大幅动作。
不要写实表演，不要真实武术动作。

【避免项】
禁止3D感、真人摄影感、写实皮肤、电影级光影、景深、真实材质、写实特效、高斯运动模糊、流体特效。
禁止角色特征互换、禁止五官融合、禁止生成第三个介于两者之间的角色、禁止两人脸部相似。
禁止脸崩、五官变化、发型变化、服装变化、武器消失、肢体畸形、多手多脚、手指错误、穿模。
禁止两人手部在前景交叠、禁止武器在同一帧交叉、禁止锚位左右互换。
禁止5人以上同框、禁止无序混战、禁止两人同时释放技能。
禁止普通淡入淡出、空镜头、长时间静止、重复机位、连续正面平视。
禁止未成年外观（如角色为成年）、过度暴露、低俗内容、现有IP/Logo/水印。

【核心目标】
重点突出两名角色各自的魅力与二者之间的<替换关系>张力、清晰的视觉区分度、大透视多机位变化、纯二维平面设计感。整支片子像一支关系张力鲜明、双主角identity清晰、转场紧凑的双人角色PV。
```

## 关系类型 → 同框构图替换参考

| 关系 | 7-10s 同框构图 | 13-15s 最终构图 |
|---|---|---|
| 宿敌 rival | 背对背站立，视线朝相反方向 | 左右对峙，中央留白 |
| 同伴 ally | 并肩前行，两人同向 | 并肩定格，同时面向镜头 |
| 师徒 mentor_student | 高低位差，师在后上方 | 前后错位，徒在前 |
| 血亲 siblings | 左右镜像对称姿态 | 镜像定格 |
| 对立阵营 opposing | 画面被图形分割，各占一格 | 分割定格，中线分明 |

## 5s / 30s 适配

- **5s**：取 `0-2s`（A 登场）+ `2-4s`（B 登场）+ `13-15s`（双人定格），
  压缩为 `0-1.5s / 1.5-3s / 3-5s`。**5s 不做同框关系段**，
  因为来不及先建立个体识别，同框必然导致两人都记不住。
- **30s**：在 `7-10s` 关系段前后各扩展一段个体高光，
  同框段可扩展至 3 段（起势 / 对峙 / 收势），仍须保持静态。

## 风险自检

- [ ] 两人是否至少 2 维强对比？
- [ ] 首个 Shot 是否为 lead 单人？
- [ ] 每人是否都有独占 Shot？
- [ ] 同框段落是否全为静态姿态（无大幅动作）？
- [ ] 锚位是否全片一致？
- [ ] Negative prompt 是否显式禁止特征互换？
- [ ] 同框总色数是否 ≤ 5？
