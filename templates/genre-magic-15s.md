## 完整可替换模板

```
生成一支约15秒、16:9横版、原创魔法幻想JRPG角色宣传PV。
整体采用纯二维日式赛璐璐动画 + 魔法阵Graphic平面设计 + 高冲击力动漫海报动态视觉。全片保持纯二维，禁止3D建模、CG渲染、真人摄影感、写实皮肤、真实空间纵深、写实流体特效。

【角色设定】
角色外观严格参考输入角色：<替换为角色外貌：发型/发色/瞳色/服装/法器/配饰>。
气质：<如：神秘优雅、高冷疏离、燃系热血、甜美魔法少女>。表情可包括：闭眼蓄力、睁眼爆发、吟唱、抬手施法、自信微笑、冷峻凝视。
角色一致性强制约束：发色、瞳色、服装、法器全程一致，禁止脸崩、禁止五官变化、禁止服装随机变化、禁止肢体畸形、禁止手指错误、禁止法器消失。
魔法属性：<明确属性，如：火焰/冰霜/雷电/暗影/圣光/自然/时空>，魔法光效主色为<能量色>。

【主题设定】
主题为"<替换主题名，如：ARCANE AWAKENING / 奥术觉醒>"。
故事发生在一个由魔法阵、符文、几何结界、能量粒子、魔法光带、星象图、炼金术符号、空间裂纹、古籍书页、悬浮水晶组成的抽象魔法空间。
主色：<角色主色> + 能量色 + 纯黑 + 纯白 + 金色/银色（魔法金属色），高对比梦幻光影。
原创角色，原创魔法世界，原创标题，不出现现有IP和Logo。

【音乐】
120-140 BPM日系幻想电子 / Orchestral Electro / 魔法系Game OST，融合弦乐合奏、唱诗班和声、电子鼓、低沉Bass、魔法音效（吟唱/符文激活/能量充能/爆发轰鸣/粒子飘散）、合成器琶音、钟声。
开场用低沉弦乐+吟唱+能量充能声制造神秘感，0.5s内出现角色。
中段蓄力阶段弦乐渐强，鼓点进入，每一次符文激活对应一次音效。
爆发阶段鼓点加密、弦乐齐奏、唱诗班爆发，每一次重拍对应一次能量释放或切镜。
结尾在最强爆发后音乐突然收束，以一个钟声+粒子飘散声+余韵结束。

【画面风格】
人物使用精致黑色轮廓线、平涂色块、块状分层硬阴影、高亮光效，非写实光影。
魔法特效为纯二维块状分层手绘光效：几何魔法阵纹路清晰、粒子分层飘散、色块堆叠光影、能量光带规整流畅、结界符文发光。
背景由魔法阵、符文环、几何结界、能量粒子、星象图、炼金术符号、空间裂纹、悬浮水晶、古籍书页碎片构成。
整体像魔法少女动画变身名场面、JRPG必杀技演出、幻想游戏角色PV、魔法阵平面设计海报。

【动态与转场总要求】
全片快慢节奏结合，蓄力阶段舒缓，爆发阶段高密度切镜（0.3-0.8s），禁止长时间静止，禁止普通淡入淡出，禁止空白过渡。
转场使用：光效形态匹配（能量从圆形扩散为下一幕背景）、几何划像（魔法阵旋转切割画面）、色彩渐变溶解、能量波纹扩张、粒子飘散遮挡、符文激活闪屏、空间裂纹撕开、魔法阵旋转切镜、闪白（仅爆发瞬间1帧）。
多层叠加运动：前景粒子/符文飞入、中景人物施法动作、后景魔法阵旋转脉冲、能量光带同步流动。
可闪现原创魔法文字：<如ARCANE/AWAKENING/ELEMENTAL/RELEASE/SEAL BREAK/MAGIC CIRCLE NO.01>，必须是原创设计感符文文字。

【分时间段镜头设计】
0-1.5s：超近距离脸部特写，角色双眼闭合，长睫毛低垂，嘴唇微动似在吟唱。额头/手部浮现微弱<能量色>符文光。瞬间插入：眼睛特写（闭）→指尖符文→法器细节→魔法阵碎片。伴随低沉吟唱声、能量充能声、主题文字碎片浮现。机位：正面贴脸特写。
1.5-3s：切换为中景，镜头以小角度（30°）缓慢环绕角色，匀速推进。角色表情肃穆，能量色光从下方映照面部。背景星象图缓慢旋转，粒子开始上浮。机位：中景环绕缓推。
3-4.5s：突然切到45°侧上方近景，角色一只手高高举起，掌心能量球快速膨胀，块状分层光效旋转堆叠。另一只手向后伸展保持平衡。角色睁眼，<能量色>瞳孔发光，表情从肃穆转为坚定。能量球溢出的粒子向四周飘散，遮挡镜头完成转场。机位：侧上方近景。
4.5-6s：切换到低机位仰拍全景，角色悬浮于魔法阵中心，周身环绕3-5层旋转的符文环，能量光带从脚下向上升腾。背景空间裂纹撕开，露出内层星空/异空间。镜头快速拉远展示全貌，角色姿态舒展如神祇。魔法阵发出嗡鸣声，唱诗班和声进入。机位：仰拍全景快拉。
6-7.5s：爆发阶段开始，高密度快切。连续闪现：1. 角色面部特写（睁眼吟唱爆发）；2. 手部/法器能量爆发特写（块状光效炸裂）；3. 魔法阵全速旋转俯视；4. 能量波纹向四周扩散的全景。每段0.3-0.5s，伴随闪白1帧、镜头微震（5-8px）、鼓点重击。机位：贴脸→特写→俯视→全景快速切换。
7.5-9s：切换到正面超广角近距离，角色向镜头俯冲/伸出手，能量从掌心向镜头方向爆发，形成巨大的<能量色>能量柱冲向观众。角色表情凌厉/自信，头发和服装被能量气流吹起。能量柱由块状分层光效构成，粒子分层飞溅，无流体效果。机位：正面俯冲撞镜。
9-10.5s：切换到大角度荷兰角，角色单膝/半蹲落地，能量从接触点向四周爆发形成环形冲击波，地面/空间裂纹扩散。角色一只手撑地，另一只手仍维持能量，抬头看向镜头。周围符文环碎裂成粒子飘散。画面随鼓点进行色彩反相、能量色闪切、空间裂纹抖动。机位：荷兰角低角度。
10.5-12s：镜头从能量爆发中心缓慢拉远，角色站立于魔法阵残骸中心，周身残余能量粒子缓缓下落，符文环逐渐消散。角色表情从凌厉回归平静/自信，放下手臂，法器/手部光效减弱。背景空间裂纹缓慢愈合，星象图恢复稳定旋转。音乐从高潮逐渐收束。机位：正面全景缓拉。
12-13.5s：切换到近距离侧仰拍，角色侧身站立，侧脸被残余能量光照亮，一只手轻轻抬起，指尖残留最后一点<能量色>光粒子飘散。角色微微侧头看向镜头，露出神秘/自信的微笑。头发和服装轻微飘动。背景虚化的魔法阵缓慢旋转，粒子如雪花飘落。机位：侧仰拍近景。
13.5-15s：最后切换为正面中景/全景主视觉定格。角色站在完整魔法阵中心，姿态优雅舒展，法器/手部维持微弱光效，周身环绕一圈稳定旋转的符文。直视镜头，表情最有记忆点。背景所有魔法阵、符文、粒子、星象图瞬间规整排列，完成最终魔法海报定格。最后0.3s：角色眨眼/指尖光粒子最后飘散→画面定格。巨大原创标题<主题名/角色名>伴随钟声+余韵结束。机位：正面中景/全景主视觉定格。

【表演要求】
角色动作保持强烈二次元魔法动画感，蓄力阶段沉稳优雅，爆发阶段凌厉有张力，带魔法少女/JRPG必杀技的仪式感。
动作包括：闭眼吟唱、结印、举法器、抬手施法、悬浮、俯冲、落地、能量释放、收招、回眸微笑。
不要写实表演，不要真实武术，不要夸张肢体形变（能量爆发可轻微形变）。

【避免项】
禁止3D感、真人摄影感、写实皮肤、电影级光影、景深、真实材质、写实流体特效、高斯运动模糊、真实粒子物理。
禁止角色脸崩、五官变化、发型变化、服装变化、法器消失、肢体畸形、多手多脚、手指错误、穿模。
禁止普通淡入淡出、空镜头、长时间静止、重复机位、重复动作、连续正面平视、无变化慢铺垫。
禁止魔法特效变成写实火焰/水流/烟雾，必须是块状分层手绘光效。
禁止未成年外观（如角色为成年）、过度暴露、低俗内容、现有IP/Logo/水印。

【核心目标】
重点突出角色魔法魅力、蓄力爆发节奏对比、块状分层手绘光效、大透视多机位变化、魔法阵平面设计感、纯二维赛璐璐质感。整支片子像一支仪式感强、特效炸裂、节奏分明的魔法幻想角色必杀技PV。
```

## 5s / 10s 适配

- **5s**：取 `0-1.5s`（闭眼吟唱建立）+ `6-7.5s`（爆发快切精华）+ `13.5-15s`（主视觉定格）三段，
  压缩为 `0-1.5s / 1.5-3.5s / 3.5-5s`，蓄力极短直接爆发
- **10s**：取 `0-1.5s` + `3-4.5s` + `6-7.5s` + `9-10.5s` + `13.5-15s` 五段，等比压缩
- 任何时长都必须保持：蓄力→爆发→收尾三段结构、机位至少变化 3 次、魔法特效必须块状分层手绘、最后 0.5s 定格 + 标题
