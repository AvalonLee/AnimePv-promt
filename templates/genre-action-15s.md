## 完整可替换模板

```
生成一支约15秒、16:9横版、原创热血战斗JRPG角色宣传PV。
整体采用纯二维日式赛璐璐动画 + 战斗漫画分镜风格 + 高速MG平面设计。全片保持纯二维，禁止3D建模、CG渲染、真人摄影感、写实皮肤、真实空间纵深。

【角色设定】
角色外观严格参考输入角色：<替换为角色外貌：发型/发色/瞳色/服装/武器/配饰>。
气质：热血、凌厉、斗志昂扬、带一点狂气。表情可包括：怒吼、咬牙、锐利眼神、挑眉、自信坏笑、战斗呐喊。
角色一致性强制约束：发色、瞳色、服装、武器全程一致，禁止脸崩、禁止五官变化、禁止服装随机变化、禁止肢体畸形、禁止多手多脚、禁止手指错误。

【主题设定】
主题为"<替换主题名，如：BREAK LIMIT / 突破极限>"。
故事发生在一个由战斗漫画分镜框、速度线、冲击波纹、碎石、火花、能量色块、漫画拟声词（ドン/バキュン/ゴゴゴ）、几何裂纹、黑色墨迹组成的抽象战斗空间。
主色：<角色主色> + 纯黑 + 纯白 + 能量色（如红/蓝/金），高对比高饱和。
原创角色，原创战斗世界，不出现现有IP和Logo。

【音乐】
140-160 BPM日系战斗摇滚 / Electro Metal，融合失真吉他、快速双踩鼓、低沉Bass、铜管合奏、战斗嘶吼、冲击音效、碎拍合成器。
开场0.5s直接用重击鼓点+吉他riff切入，不做慢铺垫。
中段鼓点持续加速，每一次重拍对应一次打击或切镜。
10s后进入高潮，连续爆发鼓点+铜管齐奏。
结尾在最强一击后突然静音，以一个金属余音+碎石落地声结束。

【画面风格】
人物使用粗黑漫画线条、大面积纯色块、硬边阴影、白色高光，非写实光影。
背景由战斗漫画分镜框、放射状速度线、冲击线、碎石飞溅、火花、能量色块、漫画拟声词文字、几何裂纹、黑色墨迹、网点纹理构成。
整体像少年漫画战斗名场面、热血动画OP、游戏战斗PV高速混剪。

【动态与转场总要求】
全片按150 BPM建立Beat Grid（每拍0.4秒），平均0.25-0.8秒一次可感知事件；事件可以是硬切、姿态变化、镜头急停、图形冲击、表情变化、文字命中或单帧闪白。禁止把“3秒生成片段”误当成“3秒不切镜的成片镜头”。
转场使用：闪白硬切、冲击拉伸转场、运动轨迹匹配、速度线推切、漫画分格跳切、图形碰撞、拟声词爆闪覆盖、碎石遮挡切镜、能量波纹扩张、画面震动复位。
多层叠加运动：前景速度线/碎石飞入、中景人物战斗动作、后景分镜框/能量脉冲、拟声词文字同步爆闪。
可闪现原创战斗文字：BREAK LIMIT / COUNTER / CRITICAL / FINAL STRIKE / WARNING / DANGER。

【Beat Grid与微镜头】
150 BPM，每拍0.4秒。关键事件表：0.0眼神亮起 / 0.4武器细节硬切 / 0.8剪影揭示 / 1.6英雄仰拍 / 2.4蓄力急停 / 3.2冲刺启动 / 4.0命中闪白 / 4.8收势定格 / 5.6漫画分格 / 6.4表情呼吸 / 7.2挑衅手势 / 8.0第二轮启动 / 8.8武器轨迹匹配 / 9.6能力展开 / 10.4三机位爆闪 / 11.2必杀命中 / 12.0全景爆发 / 12.8瞬时抽空 / 13.6英雄Pose / 14.4角色名与标题。

【分时间段镜头设计】
【Generation Clip设计】
以下五段必须分别编译为五条模型Prompt。每段只允许一个主动作、一个运镜、一个主特效；段内时间点是后期可剪辑节点，不要求模型自行完成场景切换。
0-3s：主动作=拔出武器；起始姿态=手按武器，结束姿态=低机位持械警戒；可剪辑节点：0.0眼神特写、0.4武器细节、0.8剪影转角色、1.6拔出瞬间、2.4英雄姿态。机位：正面贴脸短推→低机位急停。
3-6s：主动作=侧向突进挥击；动作相位：3.0准备压低重心、4.0命中闪白、5.2收势滑停；可剪辑节点加入侧面中景、手部特写、武器轨迹、荷兰角收势。机位：侧面跟拍→荷兰角急停。
6-9s：主动作=从收势姿态起身并挑衅；这是能量对比段，不使用慢动作；可剪辑节点：6.0单膝、6.4垂眼、7.2抬头坏笑、8.0手势撞镜、8.8武器轨迹遮挡。机位：高位斜俯拍→鱼眼近景。
9-12s：主动作=释放一次标志能力；动作相位：9.0蓄力、10.4展开、11.2冲击、11.8恢复；可剪辑节点用三种构图呈现同一个动作，不新增连招；特效为块状二维能量。机位：侧仰拍短距部分环绕→急拉。
12-15s：主动作=完成收招英雄Pose；12.0爆发全景、12.8瞬时静音与图形抽空、13.2角色前进一步、13.6武器伸向镜头、14.4角色名与标题、14.8眨眼定格。机位：高位全景急拉→超低机位英雄定格。

【表演要求】
角色动作保持强烈二次元战斗动画感，夸张、利落、有张力，带少年漫画式的热血与狂气。
候选动作包括：出拳、踢腿、挥武器、冲刺、变向、跳跃、落地滑行、蓄力、爆发、转身、收招、挑衅手势。单支15秒方案只选择其中2-3个主动作，不得全部注入。
不要写实表演，不要真实武术动作，不要慢动作。

【避免项】
禁止3D感、真人摄影感、写实皮肤、电影级光影、景深、真实材质、写实特效、高斯运动模糊、流体特效。
禁止角色脸崩、五官变化、发型变化、服装变化、武器消失、肢体畸形、多手多脚、手指错误、穿模。
禁止普通淡入淡出、空镜头、慢节奏铺垫、长时间静止、重复机位、重复动作、连续正面平视。
禁止未成年外观（如角色为成年）、过度血腥、低俗内容。

【核心目标】
重点突出角色战斗魅力、高密度高转场、热血漫画感、大透视多机位、能量爆发视觉冲击、纯二维平面设计感。整支片子像一支节奏极强、转场极密、打击感炸裂的热血战斗角色PV。
```

## 5s / 10s 适配

- **5s**：使用 Hook / Impact / Hero 三个 Generation Clip；微镜头仍保持 6-10 个
- **10s**：使用 Hook / First Impact / Contrast / Climax / Hero 五段能量结构；微镜头 10-18 个
- 任何时长都必须保持：机位至少变化 3 次、禁止单镜头到底、最后 0.5s 定格 + 标题
