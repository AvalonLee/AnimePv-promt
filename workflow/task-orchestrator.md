# 任务调度器

本文件解释唯一执行源 `skill/execution-flow.yaml`，不得自行定义另一套流程。

## 支持任务

| 任务 | 用途 |
|---|---|
| `create_video` | 从角色设定到平台提示词的完整流程 |
| `optimize_prompt` | 诊断并修改已有视频提示词 |
| `compile_platform_prompt` | 将合格导演方案转换为平台格式 |
| `analyze_reference` | 拆解参考方案和可复用规律 |
| `ingest_case` | 摄取、审查、去重并索引案例 |
| `character_profile` | 只完成角色设定、身份锁定和主视觉 |

## 完整制作任务

### 第一阶段：角色与主视觉

识别任务和角色材料，完成角色分析、身份锁定、单人或多人判定及主视觉设计。用户确认后才能继续。

### 第二阶段：方向与视频设计

依次确定内容类型、创意方向、表现策略和风格，再执行导演编排、节奏规划、组件匹配、分镜、文字图形与音乐音效卡点设计。用户确认后才能继续。

### 第三阶段：校验与平台交付

先选择平台、生成方式并登记素材，再建立完整统一导演方案。随后执行严格结构校验、分阶段风险评估、质量评分、自动修改和复检；通过后编译。用户最终确认后交付。

## 调度规则

- 复杂任务按阶段串行，不把角色补全、导演设计和平台编译合并成一次输出。
- 参考分析可以先于角色设计，但提取规律必须标注证据等级。
- 质量不通过时回到自动修改，不允许绕过质量门槛直接编译。
- 平台转换只改变表达方式，不重新决定角色、节奏或分镜。
- 实际图片或视频生成必须另行获得用户明确确认。
