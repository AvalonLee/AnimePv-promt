# Occasion Director（纪念与节令向群像导演器）

适用：纪念向 PV（回顾型）、节令氛围 PV（季节型）、跨风格对话 PV（双风格碰撞型）。

> **与角色 PV 的根本差异**：角色 PV 卖「认识一个角色」，
> 纪念/节令向 PV 卖「置身一段共同经历」。
> 前者的成功标准是**记住角色**，后者是**唤起情绪共鸣**（回忆 / 氛围 / 期待）。
>
> 本文档为**可选规则**（移植自主线活动向导演器，去商业化重构）：
> CTA 转化要求已移除，收尾改为「信息帧」；阵容与 DNA 规则仍强制。

---

## 三条硬性差异

### 1. 收尾信息帧

角色 PV 可以只留标题。纪念/节令向 PV 结尾**建议**包含：

```
主题标题 + 系列标识（作品名 / 主题字样）
```

信息帧用于情绪落点与记忆锚定，不承担转化职能。

### 2. 情绪曲线不同

| 类型 | 曲线 | 与角色 PV 的区别 |
|---|---|---|
| 角色 PV | 好奇 → 认识 → 想要 | 单主角认知建立 |
| 纪念向 | 回顾 → 感谢 → 展望 | 群像共同记忆 |
| 跨风格对话 | 意外 → 融合 → 期待 | 双风格碰撞与互补 |
| 节令向 | 氛围 → 惊喜 → 呼应 | 环境先行，角色点题 |

### 3. 节令向是唯一允许弱化角色开场的类型

角色 DNA 锁定规则不变。节令向的开场（0-3s）可用环境建立节日氛围，
此处角色占比可降至 30%，但**全片平均仍须回到 70%**。
这是明确的受控例外，不是放宽规则。

## 15s 纪念向结构

```
0-2s     MILESTONE     纪念标识 / 回顾性数字意象
2-5s     LEAD          主打角色单人
5-9s     ROTATION      阵容轮换（老角色回归感）
9-12s    ENSEMBLE      全阵容列队同框
12-15s   信息帧        主题标题
```

阵容规模建议 3 人。`ENSEMBLE` 段必须使用 `action_level 1` 组件。

## 15s 跨风格对话结构

```
0-2s     COLLISION     双方视觉符号碰撞
2-5s     SIDE A        风格 A 角色呈现
5-8s     SIDE B        风格 B 角色呈现
8-12s    CROSSOVER     跨风格同框（风格对比是看点）
12-15s   信息帧        主题标题
```

## 15s 节令向结构

```
0-3s     ATMOSPHERE    季节环境（允许角色占比 30%）
3-7s     COSTUME       节令造型展示
7-11s    INTERACTION   角色互动 / 节令动作
11-15s   信息帧        主题标题
```

---

## 30s 纪念向

```
0-6s     里程碑 + 世界回顾
6-14s    阵容轮换（4-6 人，靠出场顺序而非同框）
14-21s   高光集锦（快切）
21-27s   全阵容列队
27-30s   信息帧
```

> 4 人以上**禁止同框**，须靠出场顺序建立群体感。见 `core/multi-character/weight-rules.yaml` 与 `cast-schema.yaml` 的 `crowd_policy`。

## 纪念/节令向的风险特征

天然比单角色 PV 风险高，原因：阵容规模大 + 需要同框。

| 类型 | 建议阵容 | 稳定性上限 | 主要风险 |
|---|---|---|---|
| 节令向 | 2 | 32 | 节令造型与原 DNA 的冲突 |
| 跨风格对话 | 2 | 32 | 跨风格视觉不统一 |
| 纪念向 | 3 | 28 | 身份串味、阵容色彩打架 |

### 节令造型与 DNA Lock

节令/跨风格限定造型本质是换装，与 DNA Lock 的 `costume_change: critical` 冲突。
处理方式同 `transformation_exception`，见 `core/character-dna/forbidden-changes.yaml` 的 `costume_variant_exception`：

```yaml
costume_variant_exception:
  must_remain_identical: [face, hair_color, eye_color, signature_asset]
  may_change: [costume_form, accessory_theme]
  constraint: 造型变化须全片一致，不得在片中切换回原造型
```

---

## 跨风格对话的原创边界

本系统**仅产出原创设计描述**。跨风格对话 PV 中：

- ❌ 不得在 Prompt 中描述现有 IP 的具体角色外观
- ❌ 不得生成他方 IP 的 Logo / 标识
- ✅ 可描述「跨风格碰撞」的构图与氛围
- ✅ 对方角色素材须由用户自行提供并确保已获授权

见 `core/prompt-structure.md` 的原创声明要求。

## 自检

1. 结尾是否有主题标题的**信息帧**？
2. 情绪曲线是否匹配类型（而非套用角色 PV 的「好奇→想要」）？
3. 阵容是否满足 contrast_requirement（任意两人 2 维强对比）？
4. 同框段落是否只用了 `action_level 1` 组件？
5. 节令造型是否保持了 face / hair_color / eye_color / signature_asset？
