# 角色 PV 快切分镜脚本（默认 8 镜版）

适配三类风格（打斗 / 日常文戏 / 魔法幻想）通用逻辑。
总时长 13s（可按 `SESSION_SPEC.duration` 等比调整）。
默认快切节奏：单镜头 1-2s，多角度，镜头转动高效快速，含英雄镜头。

---

## 镜头 1：开场英雄镜头 · 快切登场（0-1.5s）

| 维度 | 内容 |
|---|---|
| 时长 | 1.5s |
| 景别 | 全景 → 面部特写 |
| 镜头运动 | 低机位仰拍快速上摇甩镜，0.3s 内完成仰拍→贴脸，速度线拖尾 |
| 画面内容 | 角色剪影登场瞬间切入面部特写，眼神直视镜头，标志配饰一闪而过；极简背景低饱和衬底 |
| 动态表现 | 甩镜带来的速度感 + 发丝/衣角瞬间甩动，开场即建立气场 |
| 转场方式 | 闪白硬切 + 主题文字碎片撞入 |
| 核心 Prompt | 赛璐璐开场英雄镜头，低机位仰拍快速甩镜上摇，贴脸特写收束，速度线爆发，12fps有限动画 |

## 适配说明

| 类型 | 镜头 1/3 调整 | 镜头 5/6 调整 | 镜头 7/8 调整 |

| 打斗 | 武器/拳套 macro 特写 | 肢体连招 + 打击命中 + 冲击特效 | 英雄定格 pose |
| 日常文戏 | 配饰/眼睛特写 | 微表情 + 肢体语言多角度快切 | 角色海报 pose |
| 魔法幻想 | 魔法阵/法器特写 | 技能释放 + 块状光效快切 | 魔法阵定格 |

> 若用户明确要求「舒缓 / 氛围文戏」，可退回 4 镜慢速版：
> 静态登场 → 极缓推进 → 慢环绕爆发 → 收尾定格（单镜 3s+）。
> 默认一律使用上方 8 镜快切版。
