# 人物表演设计

目标：让角色像正在经历事件，而不是为了镜头摆姿势。先设计人物状态，再决定镜头。

## 表演四段

适用于日常、剧情、情绪、角色展示及动作前后：

1. 原本状态：角色原本正在做什么。
2. 外界刺激：声音、光线、人物、道具或环境发生什么变化。
3. 即时反应：眼神优先，随后表情、手部、重心与身体方向变化。
4. 继续/收束：角色继续原动作、改变行动、掩饰反应或进入下一动作。

动作高潮继续使用“准备 → 爆发 → 收势”，但准备与收势应尽量包含可读的表演信息。

## 生命感镜头卡

```yaml
performance_shot:
  character_id: lead
  current_activity: 正在擦拭刀刃
  attention_target: 刀面突然映出的身后人影
  stimulus: 身后出现轻微金属声
  reaction: 眼睛先抬起，左手停止擦拭，身体重心前移
  body_balance: 坐姿放松转为前倾准备起身
  hand_task: 右手握刀，左手停在刀背
  expression_transition: 平静 → 察觉 → 警觉
  environment_response: 窗帘受风扫过前景，冷光移动到瞳孔
  captured_moment: 已察觉危险但尚未拔刀
  camera_motivation:
    purpose: 捕捉角色意识到危险的一瞬间
    distance_reason: 需要看清瞳孔反光和嘴角停顿
    movement_reason: 从刀面反光引导到眼睛
    foreground_reason: 帘布制造自然遮挡切点
    exit_condition: 角色完成起身后切到全身动作镜头
```

## 硬规则

- 主要角色镜头必须有具体行为，不能只写“站立、帅气、坚定”。
- 行为必须有对象、原因或目标；表情应由事件触发。
- 手部至少承担一项明确任务；身体写明重心或动作趋势。
- 环境至少有一项对角色产生影响，或由角色动作产生反馈。
- 推近、跟随、甩镜、低机位、遮挡都要有理由；禁止无目的环绕。
- 15秒角色视频优先至少包含：1个未完成动作/表情转换、1个外界触发反应、1个动作或情绪余韵。
- 多角色镜头分别声明注意对象和反应时差，避免所有人同时做同一动作。
