# 角色概念分解图（Character Concept Breakdown Sheet）

> 本资产是 Step1「角色设定图 Prompt」的**深度扩展层**，面向需要一次性呈现角色全貌的设定稿场景：
> 单张图内同时交代「全身造型 + 服装分层 + 表情区间 + 材质细节 + 生活切片」。
> 与 [character-card-template.md](character-card-template.md) 互补——后者产出单张角色立绘，
> 本资产产出**全景式分解图**，二者共享同一套角色设定卡与 Base Style 锁定。
> 风格锁定细则见 [core/style-anchor.md](../core/style-anchor.md)。

适用场景：
- 角色 PV 上线前的**视觉圣经（Character Bible）定稿稿**
- 美术 / 视觉风格对齐用的**角色设定分解图**
- 任何需要「一眼看懂这个角色怎么穿、什么气质、私下沉溺什么」的场合

性别通用：六维框架适用于所有角色；本文以**男性 / 女性 / 中性三套种子矩阵**呈现——
男性向内容见各 `male-*` 主题，女性向内容见各 `*girl` / `academy` / `magic-girl` / `dark-witch` 主题，
中性 / 非二元内容见 `character-release` / `ability_showcase-legendary` 两个性别中立主题。
三版结构完全同构，仅「背景色调」「生活切片三桶示例」「做旧痕迹」按气质微调（见第 1、4、5 节）。

---

## 1. 风格锁定（继承 core/style-anchor.md）

概念分解图**不改变**已选定的 Base Style。无论中心立绘还是周边拆解小图，必须：

1. 选定 Base Style 后全图锁定，禁止中途切换；7 套 2D base 见 [core/style-anchor.md](../core/style-anchor.md)。
2. 纯 2D：禁止 3D CGI、三维建模、真人摄影感、写实 PBR 材质、实拍运镜。
3. 角色 DNA 全程一致：中心人物与周边拆解的脸部 / 发型 / 服装 / 配饰 / 标志物不可变化。
4. **白底设计稿变体**：本资产允许使用浅色稿纸背景以营造手稿专业感，
   这是**呈现方式**而非画风切换——线稿、渲染、光影仍须服从所选 base style。
   例如 `modern-cel` 的分解图仍是赛璐璐平涂 + 硬边阴影，只是背景换成浅底。
   **性别化背景色（呈现层差异，不触发画风切换）**：
   - 男性向默认「纯白 / 浅灰稿纸」；
   - 女性向默认「米黄 / 羊皮纸 / 浅灰纹理背景」，可叠加极淡网格 / 点阵 / 牛皮纸噪点强化手账质感，
     但禁止引入写实照片底、3D 材质底或强噪点插画底；
   - 中性 / 非二元角色在上述两者间按气质二选一（清冷感选白底，温润/复古感选羊皮纸）。

## 2. 构图布局（Composition）

```
          ┌─────────────────────────────────────────┐
          │    [手写标题：角色名 / 代号 / 定位]          │
          │                                             │
  表情集   │        ╭───────────────╮                  │   材质特写
  (3-4头)  │        │  中心全身立绘   │  ←引导线→ 皮质纹理 / 金属反光
 冷峻/松弛  │        │ (视觉锚点)      │                  │
 专注/不耐  │        │ 肩宽·腰线比例   │                  │
          │        ╰──────┬────────╯                  │
          │      引导线┃ (连接各拆解物)                │
          │   ┌──────┴───────┐                        │
  服装分层   │  外套/衬衫/裤/内搭  ──引导线──→ 中心对应部位   物品质感特写
  (单品拆解) │  内层状态(脱外套)   手腕表带 / 打火机工艺      │
          │                                             │
  生活切片   │  包袋+内容物 │ 护理物件 │ 私密收藏              │
  (三桶)    │  打开的包 / 桌面陈列                          │
          │                                             │
          │   注释：纯棉打底 / 防水冲锋衣 / 复古机械表 …     │
          └─────────────────────────────────────────┘
```

- **中心位**：角色全身立绘或主动态姿势（站姿 / 半坐姿），作为视觉锚点，突出体态特征（肩宽、腰线比例）。
- **环绕位**：在中心四周空白处有序排列拆解元素，避免拥挤；用**手绘箭头 / 简约引导线**把周边物连接到中心对应部位（背包→背部、手表→手腕、内搭→躯干）。
- **注释**：每个拆解元素旁模拟手写注释，说明材质（纯棉打底）、功能（户外多功能腰带）或品牌 / 型号暗示（复古机械表、战术工装裤），简洁不冗余。

## 3. 六维拆解框架（Breakdown Dimensions）

每维都映射到 `schema/character-bible.schema.yaml` 的字段，确保与角色圣经同源。

| # | 维度 | 拆解内容 | 映射字段 |
|---|---|---|---|
| 1 | **服装分层** | 单品拆解（外套 / 衬衫 / 裤子 / 内搭）；多层穿搭展示脱外套后的内层状态（解领口、挽袖口）；突出层次感（工装外套+打底T / 西装+马甲） | `visual_identity.outfit` + `color_palette` |
| 2 | **私密内着拆解** | 独立展示内层衣物（背心 / 平角内裤 / 打底衫 / 袜子 / 保暖内衣），突出设计感与材质（纯棉透气、速干、简约 logo 款） | `visual_identity.outfit`（内层扩展） |
| 3 | **表情集** | 3–4 个头部特写，捕捉眼神、眉形、嘴角微变化；男性常见冷峻 / 松弛微笑 / 专注 / 略带不耐烦，女性常见甜笑 / 自信挑眉 / 走神 / 狡黠 | `personality.emotion_range` + Expression 组件 |
| 4 | **材质特写** | 1–2 个关键部位放大（皮质外套纹理、工装裤 / 裙装布料肌理、金属配饰反光）；女性向可追加**做旧痕迹**（磨损边、褪色、使用磨痕、起球）以强化角色生活厚度 | `detail-macro` 镜头作用于 `signature_item` |
| 5 | **物品质感特写** | 小物件材质（手表表带皮质/金属、打火机磨砂/亮面、耳机塑料/金属拼接工艺） | `signature_item` 近景 |
| 6 | **生活切片（关联物品）** | 见第 4 节三桶分类，脑补角色隐藏面 | `memory_hook.memory_points` + `personality.traits` |

## 4. 生活切片三桶（Life-Slice Taxonomy）

「生活切片」是概念分解图区别于普通角色立绘的核心——它用随身物讲出角色的**隐藏面**。

三桶命名跨性别**统一**为：① 随身包袋与内容物 · ② 个护与配饰 · ③ 个性化物件。

| 桶 | 通用内容 | 男性向示例 | 女性向示例 |
|---|---|---|---|
| **① 随身包袋与内容物** | 日常包「打开」散落，交代动线与身份 | 双肩 / 邮差 / 公文包：笔记本、充电宝、钢笔、钱包、交通卡、折叠伞、数据线 | 托特 / 斜挎 / 手拿包：粉饼、口红、便签本、充电宝、钥匙扣、毛绒挂件 |
| **② 个护与配饰** | 护理物件与随身装饰，交代自律度与生活质感 | 剃须刀、保湿乳液、发蜡、防晒喷雾、便携香氛、隐形眼镜护理液 | 化妆镜、香水瓶、发饰、护手霜、首饰小盒、美甲贴 |
| **③ 个性化物件** | 私下沉溺与收藏，制造记忆点 | 复古相机、工具刀、游戏手柄、限量卡牌、补剂、电子烟、收藏徽章 | 手账本、常备药品、收藏品（徽章 / 盲盒 / 胶片）、手写便签、明信片 |

> 桶 ③ 是记忆点来源：男性向偏「工具 / 硬核收藏」，女性向偏「记录 / 治愈 / 软收藏」，中性向偏「通用收藏 / 跨性别物件（徽章 / 盲盒 / 手账 / 明信片）」，均须与角色人设自洽。
> 角色种子矩阵由当前角色设定卡与风格锚点共同生成；
> 男性种子矩阵见 [concept-sheet-matrix.yaml](../library/creative-direction/concept-sheet-matrix.yaml) 的 `male-*` 条目；
> 女性种子矩阵见同一文件的 `female` 条目（sweet-y2k-girl / cool-female-jrpg / academy-character / magic-girl / cyberpunk-girl / dark-witch-release）；
> 中性 / 非二元种子矩阵见同一文件的 `neutral` 条目（character-release / ability-showcase-legendary，生活切片采用跨性别通用示例）。

## 6. 执行逻辑（Execution Logic）

对接 AnimePv-promt 的 Step0 → Step1 流程：

1. **分析核心特征**：年龄、风格定位（工装 / 商务 / 街头 / 户外等）、穿着细节、潜在性格（沉稳 / 随性 / 热血 / 内敛）。
2. **提取一级元素**：外套、裤子、鞋子、核心配饰、大表情（直接可见项）。
3. **脑补二级深度元素**：内搭风格、包里装什么实用工具、私下收藏什么小物件——贴合角色生活习惯与设定。
4. **生成组合图**：透视准确，服装分层符合穿着逻辑，光影统一，注释清晰易懂。

全程中文注释与设计逻辑呈现。

## 8. 一致性约束（与项目定位对齐）

- **Base Style 锁定铁律**第 1、3 条同样适用于概念分解图：选定后全图不可切换，且禁止 3D 形态。
- **角色 DNA 一致**：生活切片中的私藏物属于 `signature_item` / `memory_points` 的延伸，不得与角色设定矛盾（如禁欲系角色不应出现电子烟，除非刻意制造反差并在设定中注明）。
- **效果优先**：生活切片第三桶（私密收藏）是记忆点来源，但需服务于「让玩家记住角色」，而非堆砌无关杂物。
- **风格统一**：三套男性 + 六套女性 + 两套中性（非二元）角色类型的规范分解内容已固化于 [concept-sheet-matrix.yaml](../library/creative-direction/concept-sheet-matrix.yaml)，生成时须优先采用类型既定矩阵，再做个性化微调。
- **性别化背景仅限呈现层**：女性向使用羊皮纸纹理背景、男性向使用纯白稿纸，均为呈现层差异，不改变 Base Style；中性 / 非二元角色可在「纯白稿纸」与「羊皮纸纹理」间按角色气质二选一。若所选 base 为水彩国风 / 韩漫等，羊皮纸可自然融合，但禁止引入写实照片底或 3D 材质底。
- **做旧痕迹慎用**：女性向材质特写可追加做旧痕迹以增厚生活感，但磨损 / 起球须服务于人设（如冒险系、复古系），禁欲 / 高奢系角色应克制或省略，避免与「精致」定位矛盾。
