# 使用指南

AstraForge Studio 是面向中文用户的动漫角色视频提示词导演工具。目标是先稳定角色，再追求动作、镜头、节奏和画面效果。

## 三阶段工作流

### 一、角色设定与主视觉

选择一种入口：提供初步创意、提供现成角色提示词，或上传角色图片。系统会补全角色设定、提取不可变化特征并生成主视觉图提示词。当前环境不能看图时，会给出标准图片逆推命令。

确认内容：角色设定卡、固定特征、主视觉图或主视觉提示词。

### 二、方向、视频、文字与声音

确定时长、比例、内容类型，再选择创意方向和表现策略。随后生成能量曲线、节拍事件、快切小镜头、独立生成片段、声音和文字。文字可选择后期添加、由模型直接生成或完全不使用。

确认内容：视频创意、分镜、节拍、文字策略和声音方案。

### 三、质量闭环、平台、生成方式与素材

先完成结构校验、质量评分、自动修改和复检。通过后选择即梦、MiniMax H3 官方平台或 MiniMax H3 自行部署，再选择文生、首帧、尾帧、首尾帧或多参考生成。

确认内容：平台、模型版本、生成方式、素材编号和最终提示词。

## 可执行的平台编译

```bash
python tools/validate_director_plan.py examples/platform-adapters
python tools/compile_platform_prompt.py examples/platform-adapters/jimeng-i2va.yaml
python tools/compile_platform_prompt.py examples/platform-adapters/h3-ref2va.yaml
```

即梦会输出中文分段提示词及素材选择提醒；H3 基础模式输出三个固定字段，多参考模式输出六个固定字段。自行部署版本还会给出检查点和推理参数占位信息。

五种方式不会共用同一正文：文生完整建立画面；首帧从已有姿态向后运动；尾帧逐步收束；首尾帧生成连续变化路径；多参考严格限定每份素材的继承范围。任何时间线、文字策略或素材锚点错误都会在编译前被拒绝。

## 素材引用提醒

- 即梦：通过界面素材选择器插入素材；界面显示 `@图片1` 时才按该形式引用。
- H3：按编译结果使用 `<Picture 1>`、`<Video 1>` 等标签，不与即梦语法混用。
- 素材编号必须与实际上传顺序一致，并写清每份素材参考什么、不参考什么。

## 案例摄取

案例唯一必填项是原始提示词。模型、平台、生成方式、成片和评分均为可选信息。案例会自动标记为“仅提示词”“用户反馈”或“已观察输出”，避免把没有成片的案例误当成实证案例。

```bash
python tools/ingest_case.py path/to/case.yaml
```

## 使用边界

- 工具输出的是导演方案和平台提示词，不代替实际视频生成。
- 没有主视觉参考时，角色一致性风险更高。
- 平台界面和模型能力可能更新，素材引用方式以用户当前界面为准。
- 质量检查关注角色一致性、创作意图、画面效果、动作镜头和观看节奏，不设置营销或转化指标。
