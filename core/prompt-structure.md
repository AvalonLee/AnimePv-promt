# 高质量 PV Prompt 结构规范

生成任何主题 Prompt 前必读。本文档总结自实战有效的 MiniMax H3 动漫角色 PV 案例。
生成 Prompt 时必须遵循以下 10 段结构，缺段会导致视频输出失控。

---

## 必须包含的 10 个段落（按顺序）

### 1. 开头总述

- 时长、比例、PV 类型定位（如「原创都市潮流 JRPG 角色宣传 PV」）
- 风格组合定位（默认「日本动画与日本 JRPG 角色设计语法 + 纯二维日式赛璐璐动画 + Y2K 街头潮流海报风格」；
  若指定其他 2D base style，替换为 core/style-anchor.md 中对应锚定，如「韩漫 + 动态漫画」或「厚涂 + 暗黑」）
- 纯二维强制声明：禁止 3D、禁止立体建模、禁止真实空间纵深、禁止 CG 渲染、禁止真人摄影感
- 默认日系来源强制声明：Japanese anime character design、Japanese mobile / console JRPG key visual、日系脸部比例与动漫眼睛
- 默认欧美风格反向排除：禁止 western cartoon、American animation、Disney-like、Pixar-like、DreamWorks-like、western comic-book style
  （base = western-comic 时反转：允许美漫脸部比例与夸张动态，改禁日系赛璐璐/韩漫混搭）

### 2. 角色设定

- 严格参考输入角色的外貌描述（发型、发色、瞳色、五官、服装、配饰、纹身）
- 气质关键词（如「性感、甜酷、自信、俏皮、轻微挑衅」）
- 表情清单（如「挑眉、轻笑、眯眼、歪头、眨眼、坏笑」）
- **角色一致性强制约束**：核心设计（发色、瞳色、服装、配饰）全程一致，禁止脸崩、禁止五官变化、禁止发型变化、禁止服装随机变化
- 安全边界声明（如「性感但高级，禁止过度裸露、禁止低俗」）

### 3. 主题设定

- 给 PV 起一个主题名（如「PINK NOISE」「ACADEMY STUDENT FILE」「SIGNAL」）
- 世界观描述：故事发生在什么抽象空间，由什么元素构成
- 主色板：严格控制 3-5 种主色，明确每种颜色的语义
- 原创声明：不出现现有 IP、Logo、品牌

### 4. 音乐

- BPM 范围（如 128-145 BPM）
- 音乐风格（如日系电子朋克 / Electro Pop / Future Bass / City Pop）
- 乐器/音效元素（电子鼓、Bass、碎拍、故障音效、合成器、街机提示音等）
- 段落节奏：开场/中段/结尾的音乐变化，与画面卡点对应

### 5. 画面风格

- 人物美术：按选定 base style 输出（默认日本动画角色设计语法、日系脸部比例与动漫眼睛、
  纯色填充、清晰日式手绘线稿、色块高光、非写实光影；韩漫/美漫/厚涂/水彩等
  替换为 core/style-anchor.md 对应锚定）
- 背景元素清单：具体列举由什么图形构成
- 整体视觉定位

### 6. 动态与转场总要求

- 镜头切换频率：平均每个镜头停留时间，禁止长时间停顿
- 转场方式清单：具体列举，**禁止普通淡入淡出**
- 多层叠加运动：前景贴纸飞入、中景人物动作、后景图形脉冲、文字 UI 同步跳动
- 文字元素：可闪现的原创平面文字，禁止现成品牌 Logo
- **必须区分** Micro-shot（成片剪辑单位）与 Generation Clip（模型连续生成单位）
- Action 必须提供 BPM 换算后的 Beat Grid，不接受只有 BPM 没有事件时间点

### 7. 分时间段镜头设计（最核心，精确到秒）

按时间分段描述每段画面，每段必须包含：

- **机位角度**（俯拍 / 仰拍 / 侧面 / 贴脸 / 鱼眼 / 荷兰角 / 旋转等，必须不断变化）
- **景别**（特写 / 近景 / 中景 / 全景）
- **角色动作与表情**
- **运镜方式**（平移 / 缩放 / 甩镜 / 快速切镜等，限二维）
- **转场方式**（如何进入下一段）
- **背景 / UI / 贴纸元素变化**

**机位变化强制规则**：人物每次重新出现时，必须同步改变：
镜头高度 + 镜头方向 + 身体朝向 + 手势 + 腿部姿态 + 表情。
禁止连续重复站姿、禁止连续重复正面平视。

Action 先输出 `16-28` 个 Micro-shot，再聚合为 `4-6` 个 2-4s Generation Clip。
每个 Generation Clip 必须声明起始姿态、结束姿态、一个主动作和 3-6 个 editable moments，
并逐 Clip 独立编译模型 Prompt。

### 8. 表演要求

- 动作风格：夸张、利落、张扬，二次元动画感，非写实表演
- 表情动作清单细化
- 角色主动与镜头互动（靠近 / 远离 / 俯身 / 伸手 / 回头 / 撩发等）

### 9. 避免项（禁止清单，越具体越好）

- 技术禁止：3D 感、真人摄影感、写实皮肤、电影级光影、景深、真实材质、写实特效
- 风格禁止：默认禁止欧美卡通、美国动画、迪士尼风、Pixar 风、DreamWorks 风、欧美漫画、超级英雄漫画、夸张欧美脸型、粗重矢量卡通线、橡皮管动画
  （base = western-comic 时反转，改禁日系脸部比例、赛璐璐平涂配色、韩漫喷枪渐变，防混搭）
- 角色禁止：脸崩、五官变化、发型变化、服装变化、肢体畸形、多手多脚、手指错误、穿模
- 节奏禁止：普通淡入淡出、空镜头、慢节奏铺垫、长时间静止、重复机位、重复动作
- 内容禁止（按需）：未成年外观、过度暴露、低俗、现有 IP / Logo / 水印

### 10. 核心目标

- 用 1-2 句话总结 PV 要达成的效果
- 强调角色魅力第一

---

## 时长与分段建议

| 时长 | 分段数 | 每段时长 | 特点 |
|---|---|---|---|
| 5s | 3-4 段 | 1-2s | 高密度快切，开场 0.5s 内建立角色识别 |
| 10s | 5-6 段 | 1.5-2s | 有铺垫有高潮 |
| 15s Action | 16-28 微镜头 / 4-6 生成片段 | 0.25-0.8s / 2-4s | Beat Grid + 能量曲线 + 分片生成 |
| 15s Daily | 9-14 微镜头 / 4-6 生成片段 | 0.8-1.5s / 2-4s | 轻快切与微表情 |

## 5s 短 PV 特殊处理

- 开场 0.5s 内必须建立角色强识别（脸部特写 + 核心配饰 + 主题文字碎片）
- 全程高密度切镜，无铺垫
- 最后 0.5s 定格主视觉 pose + 主题标题
- 机位至少变化 3 次，禁止单镜头到底

## 输出前自检清单

- [ ] 10 个段落是否齐全
- [ ] 是否有主题命名
- [ ] 是否区分 Micro-shot 与 Generation Clip（Action 15s：16-28 / 4-6）
- [ ] 是否输出 Beat Grid、能量曲线与可剪辑节点
- [ ] 是否含英雄镜头（开场 Hook / 高潮 / 结尾定格，15s ≥ 2 个）
- [ ] 是否有精确到秒的时间分段
- [ ] 每段是否有机位角度且不重复
- [ ] 是否有具体转场清单且禁止普通淡入淡出
- [ ] 是否有多层叠加运动描述
- [ ] 背景元素是否具体列举
- [ ] 音乐是否有 BPM 和段落描述
- [ ] 禁止清单是否具体
- [ ] 角色一致性约束是否明确
