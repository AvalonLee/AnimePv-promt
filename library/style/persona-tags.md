# 角色风格标签（Persona Tags）

P0 所有 2D base style（赛璐璐 / 厚涂 / 水彩国风 / 矢量潮流 / 韩漫 / 美漫）
共用同一套 Persona 标签。风格标签叠加在视频主题（打斗/日常文戏/魔法幻想）之上，
微调表情、光影、肢体语言，但不改变 base style 的线条与渲染方式。

---

## 与 Genre 的叠加规则

```
Genre 决定：镜头节奏、运镜参数、转场方式主框架
Persona 叠加：表情、光影、肢体语言、具体动作偏好
```

**禁止叠加**：日常文戏不叠加「激烈快速切」，打斗主题不叠加「极缓固定机位」。

## 女性角色

### 性感（气质魅惑向 · 保守非露骨）

| 维度 | 描述 |
|---|---|
| 运镜 | 慢推/小角度环绕、低角特写；突出轮廓与发丝流动 |
| 光影 | 柔光/逆光暧昧光影，肌肤与发丝高光克制 |
| 表情动作 | 回眸、挑眉、轻抿唇、撩发；姿态从容自信 |
| 节奏 | 中慢速，留白与张力并存 |
| 边界 | 气质魅惑自信，非露骨；规避违规内容 |

### 可爱（甜美元气向）

| 维度 | 描述 |
|---|---|
| 运镜 | 轻快弹跳切、快速摇镜；大眼特写 |
| 光影 | 糖果色柔光，明亮通透 |
| 表情动作 | wink、捂嘴笑、蹦跳；肢体灵动 |
| 节奏 | Q 弹明快，强律动 |

### 帅气（飒爽利落向）

| 维度 | 描述 |
|---|---|
| 运镜 | 干脆甩镜、定格；行走/战斗姿态 |
| 光影 | 硬光对比，锐利轮廓 |
| 表情动作 | 锐利眼神、利落动作；气场明快 |
| 节奏 | 明快有张力 |

### 冷酷（疏离禁欲向）

| 维度 | 描述 |
|---|---|
| 运镜 | 克制长焦固定、缓推；侧脸/背影 |
| 光影 | 冷色调，大面积留白 |
| 表情动作 | 无表情或单挑眉；疏离感 |
| 节奏 | 慢，留白多 |

## 男性角色

### 帅气（从容型男向）

| 维度 | 描述 |
|---|---|
| 运镜 | 稳健慢移、低仰角；行走/倚靠姿态 |
| 光影 | 电影感布光，层次柔和 |
| 表情动作 | 松弛微表情；气场从容 |
| 节奏 | 中速，从容不迫 |

### 冷酷（疏离禁欲向）

| 维度 | 描述 |
|---|---|
| 运镜 | 克制长焦固定、缓推；侧脸/背影 |
| 光影 | 冷色调，大面积留白 |
| 表情动作 | 无表情或单挑眉；疏离感 |
| 节奏 | 慢，留白多 |

### 热血（燃系斗志向）

| 维度 | 描述 |
|---|---|
| 运镜 | 激烈快速切、冲击变焦；动态战斗 |
| 光影 | 暖色高对比 |
| 表情动作 | 呐喊/握拳；能量感 |
| 节奏 | 强鼓点，快剪 |

## 叠加示例

| 组合 | 效果 |
|---|---|
| 打斗 + 热血 | 快切 + 呐喊 + 暖色高对比（标准热血战斗） |
| 打斗 + 冷酷 | 快切但表情克制 + 冷色调 + 利落一击（高冷战斗） |
| 日常文戏 + 可爱 | 固定机位 + wink + 糖果色柔光 |
| 魔法幻想 + 性感 | 蓄力慢环绕 + 撩发 + 逆光暧昧光影 |
| 日常文戏 + 帅气 | 干脆甩镜 + 行走姿态 + 硬光对比 |
| 魔法幻想 + 呆萌 | 柔和轻摇 + 定格表情包 + 马卡龙柔光 |
