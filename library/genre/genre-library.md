# AnimePv-promt Genre Library

Genre 决定内容类型和基础镜头节奏；角色设定、创作意图与视觉风格在其上叠加。

```
角色设定 × 创作意图 × Genre × Style = 最终视频方向
```

---

## Genre 参数对照

| 要素 | 打斗 | 日常文戏 | 魔法幻想 |
|---|---|---|---|
| 帧率节奏 | 12fps，0.3-0.8s 快切 | 12fps，0.8-1.5s 轻快切 | 12fps，快慢结合 |
| 镜头运动 | 短距快推 0.4/s，急摇 | 固定，极缓推拉 0.2/s | 缓慢环绕 30-45°，爆发快拉+微震 |
| 机位变化 | 高频切换，禁止重复 | 交错使用，禁止连续平视 | 蓄力舒缓，爆发快切 |
| 转场 | 闪白硬切、冲击拉伸、漫画分格 | 遮挡、光圈开合、图形划像 | 光效形态匹配、几何划像、能量波纹 |
| 动态表达 | 肢体挤压拉伸、速度线、残影 | 微表情、发丝微动、轻柔 | 块状分层手绘光效、粒子 |
| 音乐 BPM | 140-160 | 100-120 | 120-140 |
| 音乐风格 | 战斗摇滚 / Electro Metal | City Pop / Lo-Fi Hip Hop | 幻想电子 / Orchestral Electro |
| 最大动作等级 | 2（15s）/ 3（30s） | 2 | 2（30s+SSR 可至 3） |
| 最大特效等级 | 2 | 1 | 2（SSR 3） |

> **动作等级上限为基线**，实际预算 = `min(genre 上限, 时长上限)`，
> 并可被 `genre_ceiling_uplift` 提升（如 magic + 30s + SSR 可至 3，用于变身演出）。
> 详见 [core/quality-engine/risk-budget-gate.yaml](../../core/quality-engine/risk-budget-gate.yaml)。

## 打斗片段（Action / Combat）

热血战斗向。

- **帧率节奏**：12fps，短镜头快切，单镜头 0.3-0.8s，关键帧精简，保留手绘顿挫打击感
- **镜头运动**：短距快推（0.4/s）、水平急摇、冲击变焦、短时震动（振幅 8-12px，持续 0.2-0.5s，仅命中触发，瞬时复位）
- **机位变化**：俯拍/仰拍/侧面/贴脸/鱼眼/荷兰角高频切换，禁止连续重复机位
- **转场**：闪白硬切、冲击拉伸、运动轨迹匹配、速度线推切、图形碰撞、漫画分格跳切；**禁止普通淡入淡出**
- **动态表达**：肢体挤压拉伸、手绘放射速度线、2-3 层离散残影、块状气流/碎石特效；**禁止高斯运动模糊、禁止流体特效**
- **分镜逻辑**：全景铺垫战局 → 中景展示肢体连招 → 特写聚焦打击瞬间 → 定格高光 pose
- **音乐**：140-160 BPM 日系战斗摇滚 / Electro Metal，失真吉他、双踩鼓、铜管合奏、冲击音效
- **参考风格**：《龙珠Z》《咒术回战》老赛璐璐改编质感

## 日常文戏（Daily / Drama）

情绪叙事向。

- **帧率节奏**：12fps，单镜头 0.8-1.5s，轻快切为主，情绪高光帧可放宽到 2s；禁止长镜头站桩
- **镜头运动**：快速甩镜、多角度快切为主，辅助极缓推拉（0.2/s，全片 ≤1 处）、低速视差横移（≤0.25°/s）、小角度环绕（≤30°）；无震动
- **机位变化**：俯拍/仰拍/侧面/贴脸/过肩/荷兰角交错使用，禁止连续重复正面平视
- **转场**：物体遮挡（头发/手/身体掠过镜头）、光圈开合、图形划像、贴纸弹出、图层滑移、速度线轻推、色彩渐变溶解；**禁止普通淡入淡出、禁止空白过渡**
- **动态表达**：细微表情（眨眼/垂眸/挑眉/抿唇）、发丝微动、抬手撩发、回眸、侧身；肢体无夸张形变；**禁止高斯运动模糊**
- **分镜逻辑**：全景交代场景氛围（快切）→ 中景展示人物肢体姿态 → 近景/特写捕捉面部微表情；至少 1 个英雄镜头（回眸 / 招牌 pose 定格）
- **音乐**：100-120 BPM 日系 City Pop / Lo-Fi Hip Hop，柔和钢琴、慵懒 Bass、环境音
- **参考风格**：《魔卡少女樱》旧 TV、《堀与宫村》复古赛璐璐质感

## 魔法幻想（Magic / Fantasy）

异能特效向。

- **帧率节奏**：12fps，快慢结合；蓄力镜头 1.5-2.5s 舒缓铺垫，爆发镜头 0.3-0.8s 快切，高光特效帧短暂定格
- **镜头运动**：蓄力阶段小角度环绕（30-45°）、匀速推进；爆发阶段快速拉镜 + 轻微震动（5-8px）；全程 2.5D 平面运镜
- **机位变化**：俯拍/仰拍/侧面/贴脸/过肩/环绕交错，禁止连续重复机位
- **转场**：光效形态匹配、几何划像、色彩渐变溶解、能量波纹扩张、粒子飘散遮挡、魔法阵旋转切镜、闪白（克制使用）；**禁止普通淡入淡出、禁止空白过渡**
- **动态表达**：人物姿态沉稳，魔法特效为块状分层手绘光效（几何结界、粒子分层、色块堆叠），能量扩散轨迹规整；**禁止写实流体光效、禁止高斯运动模糊**
- **分镜逻辑**：蓄力铺垫 → 爆发 → 收尾三段结构
- **音乐**：120-140 BPM 日系幻想电子 / Orchestral Electro，弦乐合奏、唱诗班和声、魔法音效
- **参考风格**：《美少女战士》旧版、《魔卡少女樱》魔法特效、日系复古异能番赛璐璐质感

## 落地避坑总结

1. 全程坚守赛璐璐核心：**只靠速度线、残影、色块特效做动态，绝对禁止写实运动模糊、流体特效、3D 环绕运镜**
2. 节奏区分明确：打斗快切顿挫、文戏舒缓静谧、魔法快慢结合，**不混用镜头节奏**
3. 所有参数可量化、可直接输入 AI 工具，无模糊主观描述
