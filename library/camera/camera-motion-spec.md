# 运镜参数规范

所有运镜参数可量化，可直接输入 AI 工具。

---

## 通用运镜速度

| 运镜类型 | 速度 | 说明 |
|---|---|---|
| 推镜 - 慢速 | 0.2/s | 仅蓄力铺垫，情绪递进，全片不超过 1 处 |
| 推镜 - 正常 | 0.4/s | 打斗高燃，聚焦攻击 |
| 急推 / 急拉 | 0.2-0.4s 完成焦距突变 | 打击 / 爆发瞬间，快切接续 |
| 急摇 | 高速 | 打斗爆发，仅命中触发 |
| 快速甩镜 | 0.3-0.5s 完成 90-180° 扫动 | 快切转场 / 多角度衔接，默认首选 |
| 快速部分环绕 | 0.5-1s 完成 90-180° | 英雄镜头 / 能力展示，禁止完整 360° |
| 视差横移 | ≤0.25°/s | 仅日常文戏情绪镜头，全片不超过 1 处 |
| 小角度环绕 | 30-45° | 魔法蓄力，展示场地 |
| 快速拉镜 + 微震 | 5-8px 振幅，0.3s | 技能爆发，配合风压感 |
| 镜头震动 | 8-12px 振幅，0.2-0.5s | 仅打击命中瞬间触发，瞬时复位 |

> 默认节奏：快切优先。单镜头平均 1.5-2s（15s 8-10 镜），
> 禁止用慢速运镜填满整支 PV。

---

## 机位变化规则

**角色每次重新出现**时，必须同步改变全部以下维度：

1. 镜头高度（俯拍 / 平视 / 仰拍 / 鱼眼 / 荷兰角）
2. 镜头方向（正面 / 侧面 / 背面 / 45° / 旋转）
3. 身体朝向（正面 / 侧身 / 背面 / 前倾 / 后仰）
4. 手势（叉腰 / 伸向镜头 / 撩发 / 握拳 / 比心 / 指点）
5. 腿部姿态（站立 / 迈步 / 单膝 / 坐姿 / 蹲姿）
6. 表情（改变幅度、情绪、嘴角方向）

**禁止**连续两个镜头使用相同机位、相同构图或相同动作。
**多角度强制**：每段动作高潮至少 3 个不同机位快切；
15s 全片机位角度变化至少 6 次。

---

## 英雄镜头规则

英雄镜头是 PV 的记忆点，必须按配额分布：

| 时长 | 最少英雄镜头数 | 推荐位置 |
|---|---|---|
| 5s | 1 | 结尾定格 |
| 15s | 2 | 开场 Hook + 高潮或结尾定格 |
| 30s | 3 | 开场 + 高潮 + 结尾定格 |

英雄镜头实现方式（低风险优先）：

- 低机位仰拍 + 快速部分环绕（90-180°）
- 大透视正面 + 急推
- 快速甩镜接 hero pose 定格
- `camera.hero.low_angle.v1` / `camera.hero.orbit.v1` / `camera.final.pose.v1`

## 转场方式清单

| 类别 | 具体方式 | 适用 |
|---|---|---|
| 硬切 | 闪白硬切、冲击拉伸、运动轨迹匹配、快速甩镜切 | 打斗、快切默认 |
| 图形 | 图形碰撞、漫画分格跳切、速度线推切 | 打斗、Y2K |
| 覆盖 | 贴纸弹出、物体遮挡、文字爆闪 | 日常、Y2K |
| 光效 | 光效形态匹配、能量波纹扩张、粒子飘散遮挡 | 魔法 |
| 结构 | 光圈开合、几何划像、色彩渐变溶解 | 日常、通用 |
| 故障 | 故障闪断、UI 面板插入、噪点抖动、色彩反相 | 赛博、Y2K |

**禁止**：普通淡入淡出、空白过渡、无理由黑场。

---

## 动作优先级

| 级别 | 内容 | 适用 |
|---|---|---|
| A 级 | look camera / smile / turn / hair movement / hand gesture | 所有类型 |
| B 级 | weapon draw / power release / ability cast | 打斗、魔法 |
| C 级 | group battle / destruction / physics simulation | 仅限 30s 剧情(Level 3) |

默认使用 A 级 + B 级组合，避免 C 级。
