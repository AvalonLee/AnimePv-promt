# 从成功案例中提取的规则

> 来源：`角色pv教程和提示词2.md`、`动漫角色pv教程和提示词.md`、
> `赛璐璐风格三套专属视频Prompt + 四镜连贯分镜脚本.md`、
> `PV 脚本 1_太刀城市 PV.md`、`PV 脚本 2_命运赌场 PV.md`、`PV 脚本 3_兔耳魔术师 PV.md`
>
> 注：前三类为「赛璐璐动作/文戏/魔法」基线；后三类为「平面海报式 / Editorial MG / 剪影符号化」成功案例，
> 共同沉淀出第十二~十六类规则（详见 `references/cases/proven-editorial-mg-poster.yaml`）。


## 一、机位变化规则（核心：避免站桩）

每次角色出现必须同步改变：

1. 镜头高度（俯拍/平视/仰拍/鱼眼/荷兰角）
2. 镜头方向（正面/侧面/背面/45°/旋转）
3. 身体朝向（正面/侧身/背面/前倾/后仰）
4. 手势（叉腰/伸向镜头/撩发/握拳/比心/指点）
5. 腿部姿态（站立/迈步/单膝/坐姿/蹲姿）
6. 表情（改变幅度、情绪、嘴角方向）

**绝不允许**连续两个镜头使用相同机位、相同构图或相同动作。

---

## 二、角色 DNA 一致性强制约束

全片必须保持：

- 发色（禁止自动换色）
- 瞳色（禁止自动换色）
- 服装核心设计（禁止无理由换装）
- 武器/法器（禁止消失或被替换）
- 配饰（禁止消失）
- 角色年龄感（禁止变化）
- 气质（禁止变化）

**禁止**：脸崩、五官变化、发型变化、服装随机变化、肢体畸形、多手多脚、手指错误、穿模、法器消失。

---

## 三、安全边界声明

1. 性感风格限定「气质魅惑自信，非露骨」
2. 必须显式声明「禁止内衣外露、禁止走光、禁止过度裸露、禁止低俗色情表现」
3. 年龄边界必须显式声明（明确为「年轻成年女性」或相应年龄）
4. 禁止未成年外观（如角色设定为成年）、过度暴露、低俗内容

---

## 四、角色与背景分离原则

核心手法：**角色相对稳定 + 背景 Graphic 高速运动**。

- 角色占画面 70%，特效/UI 占 20%，环境占 10%
- 角色在主视觉段稳定居中，背景动态元素高速重组
- 这是控制生成风险、同时保持视觉冲击的关键手法

---

## 五、节奏控制策略

### 打斗

- 0.5s 内切入，无铺垫
- 全程高密度切镜（0.3-0.8s）
- 最后 0.5s 定格 + 标题

### 日常文戏

- 开场 0.5s 内出现角色，但允许 1-2.5s 的舒缓镜头
- 中段 1-2s 一次机位变化
- 最后 0.5s 定格 + 标题

### 魔法幻想

- 蓄力 1.5-2.5s 舒缓铺垫
- 爆发 0.3-0.8s 快切
- 高光特效帧短暂定格
- 最后 0.5s 定格 + 标题

### 通用

- 12.5s 处安排「元素散开留一瞬呼吸感」再重组，避免全程高压导致观感疲劳
- 最后 0.3s：角色眨眼 / 粒子飘散 / 画面定格 → 标题出现

---

## 六、细节快切蒙太奇

把角色卖点「逐项解锁」，比一次性全展示更有记忆点。

顺序：面部 → 发饰 → 耳饰 → 颈部配饰 → 服装 → 手部 → 签名道具

---

## 七、转场方式清单

| 类别 | 具体方式 | 适用 |
|---|---|---|
| 硬切 | 闪白硬切、冲击拉伸、运动轨迹匹配 | 打斗 |
| 图形 | 图形碰撞、漫画分格跳切、速度线推切 | 打斗、Y2K |
| 覆盖 | 贴纸弹出、物体遮挡、文字爆闪 | 日常、Y2K |
| 光效 | 光效形态匹配、能量波纹扩张、粒子飘散遮挡 | 魔法 |
| 结构 | 光圈开合、几何划像、色彩渐变溶解 | 日常、通用 |
| 故障 | 故障闪断、UI 面板插入、噪点抖动、色彩反相 | 赛博、Y2K |

**禁止**：普通淡入淡出、空白过渡、无理由黑场。

---

## 八、多层叠加运动

每帧画面三层结构：

```
前景：贴纸/文字/粒子飞入，提供速度感和即时信息
中景：人物动作核心，表情/姿态/表演
后景：背景图形脉冲/旋转/滚动，提供深度感和节奏
```

三层可独立控制速度与节奏，形成持续不断的视觉推进。

---

## 九、文字元素规则

1. 必须是原创视觉设计感文字，不是现成品牌 Logo
2. 可闪现的平面文字，一闪而过（1-2 帧），不遮挡角色
3. 拟声式短标签（HMPH. / NOT INTERESTED.）强化性格，成本低效果好
4. 文字出现方式：黑粉反相、单帧闪白、爆炸线、字体冲屏、分块撕裂、平面震屏

---

## 十、Prompt 结构规则

1. 图片 Prompt 与视频 Prompt 分离：先用 seedream5.0lite 定角色，再用 H3 做视频
2. 图片 Prompt 需指定模型、比例、数量（建议 2-4 张供挑选）
3. 视频 Prompt 分 10 段结构（见 core/prompt-structure.md）
4. 机位清单式列举（如「高机位俯拍近景 / 超低机位仰拍 / 贴脸超近距离特写」）比抽象描述更有效
5. 角色一致性约束必须显式写出，不让 AI 猜测
6. 安全边界约束必须显式写出

---

## 十一、避坑核心总结

1. 全程坚守赛璐璐核心：**只靠速度线、残影、色块特效做动态，绝对禁止写实运动模糊、流体特效、3D 环绕运镜**
2. 节奏区分明确：打斗快切顿挫、文戏舒缓静谧、魔法快慢结合，**不混用镜头节奏**
3. 所有参数可量化、可直接输入 AI 工具，无模糊主观描述
4. 人物每次重新出现必须改变机位，避免站桩
5. 角色相对稳定 + 背景高速运动 = 控制风险 + 保持冲击

---

## 十二、平面海报式 / Editorial MG 视觉规则（来自成功案例 PV）

适用：纯二维赛璐璐角色 + 抽象 Editorial MG + 游戏 UI 图层，所有元素平面化/剪影化/符号化/图形化，
像「不断拆解、翻转、重组的动态平面海报」。

1. **硬约束不可妥协**：不要 3D / 立体建模 / 三维透视 / CG 质感 / 真实空间纵深 / 景深 /
   写实光影 / 真实材质 / 连续写实打斗 / 真实摄影棚风格 / 大面积霓虹灯 / 赛博朋克写实街景（除非主题明确需要赛博）。
2. **三层结构**：前景（贴纸/文字/粒子飞入）→ 中景（人物关键姿态相对稳定）→ 后景（平面图形脉冲/旋转/反向滚动）。
3. **风险手法**：角色占比约 70% 且相对稳定（关键姿态定格 + 侧面平移），背景 Graphic 高速反向运动 —— 控风险同时维持冲击。
4. **空间符号化**：城市/世界不表现真实建筑，只保留符号骨架（管道/窗框/电线/高楼轮廓/网格/几何切片），
   所有元素像海报图层相互覆盖/切割/重组。

---

## 十三、剪影 ↔ 赛璐璐 瞬时切换手法（低成本登场/揭示）

1. 角色从「黑色剪影 → 纯白剪影 → 二维赛璐璐形象」逐段揭示，建立识别度。
2. 触发：镜头沿武器/法器杆向上移动时分面揭示；脚步/魔杖尖端划过留几何轨迹。
3. 价值：用图形语言完成登场，规避写实登场动作的生成风险；0-6s 开场固定使用。

---

## 十四、反派终场揭示结构（Villain Reveal at End）

20s PV 标准收口模板（三案例高度一致）：

1. **空间**：反派私人二维空间（剧场/酒吧/魔术台），仅由强平面色块构成。
2. **姿态**：二郎腿坐 / 转筹码 / 玩弄道具，从容危险。
3. **镜头**：极近特写；红色液体在玻璃杯旋转，杯面倒映女主剪影；几何圆环移到面部，从帽檐阴影抬眼露出微笑。
4. **标题**：原创游戏标题由主题符号（时钟/扑克/兔耳/魔术棒 + 几何切片）重新拼合，下方英文副标题。
5. 示例：太刀城市 `BEYOND THE MIRROR` / 命运赌场 `FINAL BET · PLAY YOUR FATE` / 兔耳魔术师（怀表+魔术棒+兔耳拼合）。

---

## 十五、符号化图形系统（每主题一套固定 2D 原语）

1. 每个世界主题配一套固定符号原语，重组复用即可生成无限海报感画面：
   - 城市（太刀）：时钟刻度 / 圆环 / 月相 / 扑克 / 扫描线 / 网点 / 几何切片
   - 赌场（命运）：扑克 / 筹码 / 骰子 / 概率刻度 / 游戏 UI 框线 / 网格 / 斜线
   - 魔术（兔耳）：怀表刻度 / 魔术圆环 / 月相 / 兔子符号 / 小丑笑脸 / 幕布 / 棋盘
2. **眼睛/手部特写内部嵌套世界符号图层**（瞳孔内是扑克/筹码/兔子/刻度组成的二维动画），强化角色与世界观绑定。
3. 符号库与 内容类型 一一对应，生成时优先调用既定符号集，再个性化微调。

---

## 十六、动态负向限制清单范式（必写，比模糊形容词更有效）

1. 每个 PV 末尾单列「严格限制」段，枚举**禁止项**而非只写期望。
2. 颗粒化、可判定，避免「高质量」「精美」等不可执行形容词。
3. 标准清单（可据主题裁剪）：
   - 全片纯二维平面动画（不要 3D / 立体 / 真实空间 / CG 渲染 / 三维建模）
   - 不要真实建筑 / 真实赌场 / 真实摄影棚
   - 不要电影级光影 / 景深 / 真实材质
   - 不要连续写实打斗 / 复杂连续动作
   - 不要大面积霓虹灯 / 赛博朋克写实街景（除非主题需要）
   - 所有元素平面化 / 图形化 / 插画化，像动态平面海报
4. 转场负向：禁止普通淡入淡出、空白过渡、无理由黑场（一律图形匹配转场）。
