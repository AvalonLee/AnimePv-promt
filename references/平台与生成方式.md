# 平台与生成方式

| 方式 | 输入 | 提示词重点 |
|---|---|---|
| 文生视频 | 文字 | 完整描述主体、环境、构图、动作、镜头、声音 |
| 首帧图生视频 | 首帧图 + 文字 | 少写静态外观，重点写如何从首帧开始运动 |
| 尾帧图生视频 | 尾帧图 + 文字 | 设计合理开场和逐步收束到尾帧的路径 |
| 首尾帧图生视频 | 首尾帧 + 文字 | 写清两个画面之间连续、合理的变化路径 |
| 多参考生成 | 多种素材 + 文字 | 逐项说明参考什么、不参考什么、出现时间 |

每次输出素材登记表：素材编号、类型、用途、使用范围、是否必须引用。编号必须与实际上传顺序一致。

即梦：提示用户通过当前界面的素材选择器插入素材；若界面显示 `@图片1` 等标签，再使用该标签。不同版本或接口可能不同，不承诺固定语法。

MiniMax H3：不要套用即梦标签。使用 H3 规范规定的图片、视频和音频引用标签，并保持全篇一致；写清引用内容出现的准确时间和用途。

平台版本或入口不明确时先询问。无法确认操作语法时，给出内容提示词和清晰提醒，不伪造界面或接口字段。
