# Demo — 双人（Duo / Cast=2）快切 Shot List

输入：宿敌双人 15s。角色 A（lead，左锚位，权重 45）：银发冰剑士；角色 B（second，右锚位，权重 25）：红发火术士。
依据：[director/multi-character-composer.md](../../director/multi-character-composer.md)：
同框镜头 action_level 1、锚位不互换、分格 / 分割转场优先降同框风险。

## Risk Budget

```yaml
cast: duo (size 2)
weights: { lead: 45, second: 25 }   # sum 70
action_amplification: base + 1      # 同框有效等级 +1
max_action_level_same_frame: 1
max_camera_transition: 9
shot_count: 10
hero_shot_min: 2                    # 双人各至少 1 个英雄镜头，lead ≥ 2
```

**自检**

- ✅ 快切：单镜 1.2-1.8s，10 镜 / 9 次切换 ≤ 上限 9
- ✅ 多角度：机位无连续重复；A/B 交替出场，锚位恒定（A 左 / B 右）
- ✅ 镜头转动：甩镜 #01 / #02 / #06、部分环绕 #03 / #04 / #07 / #10
- ✅ 英雄镜头 3 个（A Hook / A 高潮 / 双人收尾），lead ≥ 2
- ✅ 同框风险控制：同框镜头 action_level 1（#06 / #10），多人段落用分格转场（#05 / #09）
